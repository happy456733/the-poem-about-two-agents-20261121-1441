A short poem about agency — the power to choose and to act — and what happens when two agents agree on one plan. Two different maps of the same small field are folded away, and a single road opens only where both of them step. The program writes the poem to `entry.txt`, deterministically, with no network and no dependencies.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
